# Vaultify

Vaultify is a personal finance web app for tracking accounts, transactions, budgets, savings goals, loans, and financial trends. Built with React, TypeScript, Vite, Firebase, and Tailwind CSS, it provides a dashboard-first experience with charts, filters, and keyboard-driven navigation.

## Features

- Dashboard summaries for balances, recent activity, and trends
- Accounts and transactions with filtering by account, type, date, and category
- Budgets and savings goals with progress views
- Loan tracking and repayment workflows
- Authentication with protected routes
- Charts, motion, and responsive UI components

## Tech Stack

- React 19
- TypeScript
- Vite
- React Router DOM 7
- Zustand
- TanStack Query 5
- Firebase Authentication and Firestore
- Recharts
- Framer Motion
- Tailwind CSS
- lucide-react and @tabler/icons-react
